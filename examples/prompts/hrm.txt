Build an HRM (Human Resource Management) system in NocoBase.

## Tables (prefix: nb_hr_)

1. departments — 部门 (name, code, description:textarea, status[active/inactive]; parent m2o→departments for tree structure)
2. positions — 岗位 (name, code, level[初级/中级/高级/专家], headcount:integer, description:textarea, status[招聘中/已满编]; m2o→departments)
3. employees — 员工 (name, employee_no, phone, email, gender[男/女], birth_date:date, id_card, address, entry_date:date, leave_date:date, status[试用期/在职/离职], education[高中/大专/本科/硕士/博士], remark; m2o→departments, m2o→positions)
4. contracts — 劳动合同 (contract_no, type[固定期限/无固定期限/实习], start_date:date, end_date:date, salary:decimal, status[生效中/已到期/已终止]; m2o→employees)
5. attendance — 考勤记录 (date:date, check_in:datetime, check_out:datetime, status[正常/迟到/早退/缺勤/外勤], work_hours:decimal, remark; m2o→employees)
6. leaves — 请假管理 (leave_type[年假/事假/病假/婚假/产假/其他], start_date:date, end_date:date, days:decimal, reason:textarea, status[待审批/已批准/已拒绝/已取消], approved_by; m2o→employees)
7. overtime — 加班管理 (date:date, start_time:datetime, end_time:datetime, hours:decimal, reason:textarea, status[待审批/已批准/已拒绝]; m2o→employees)
8. payroll — 薪资发放 (period, base_salary:decimal, bonus:decimal, deduction:decimal, social_insurance:decimal, tax:decimal, net_salary:decimal, status[草稿/已确认/已发放]; m2o→employees)
9. salary_items — 薪资项目 (name, type[固定/浮动/扣除], amount:decimal, description:textarea, status[启用/停用])
10. recruitment — 招聘管理 (title, headcount:integer, salary_range, requirements:textarea, status[招聘中/已暂停/已完成], deadline:date; m2o→departments, m2o→positions)
11. candidates — 候选人 (name, phone, email, education[高中/大专/本科/硕士/博士], experience_years:integer, expected_salary:decimal, status[待筛选/面试中/已录用/已拒绝/已入职], resume:textarea, remark; m2o→recruitment)
12. interviews — 面试记录 (date:date, time:datetime, location, interviewer, result[通过/待定/不通过], feedback:textarea; m2o→candidates)
13. trainings — 培训管理 (title, type[入职培训/技能培训/管理培训/安全培训], start_date:date, end_date:date, trainer, location, budget:decimal, status[计划中/进行中/已完成/已取消]; m2o→departments)
14. training_records — 培训记录 (score:decimal, certificate, status[通过/未通过], remark; m2o→trainings, m2o→employees)

## Menu Structure

- 人力资源 (group)
  - 组织架构 (group): 部门管理, 岗位管理, 员工花名册
  - 考勤管理 (group): 考勤记录, 请假管理, 加班管理
  - 薪酬福利 (group): 薪资发放, 薪资项目
  - 招聘培训 (group): 招聘管理, 候选人, 培训管理

## Page Types (IMPORTANT — determines what blocks each page gets)

| Page | Type | JS Blocks Required |
|------|------|--------------------|
| 部门管理 | Reference | filter + table only |
| 岗位管理 | Reference | filter + table only |
| 员工花名册 | Core Business | Summary cards (总数/在职/试用期/离职) + Education/gender distribution |
| 考勤记录 | Activity | Today stats (出勤率/迟到/缺勤) + Status distribution + table |
| 请假管理 | Alert/Monitor | Pending approvals alert list + Type stats + table |
| 加班管理 | Alert/Monitor | Pending approvals alert + Monthly hours stats + table |
| 薪资发放 | Financial | Period summary (month total/paid/pending) + Status breakdown + table |
| 薪资项目 | Reference | filter + table only |
| 招聘管理 | Core Business | Summary cards (在招/已完成/暂停) + Pipeline overview + table |
| 候选人 | Pipeline | Recruitment funnel (待筛选→面试中→已录用→已入职) + table |
| 培训管理 | Target/Progress | Budget tracking + Completion rates + table |

## Phases

1. SQL DDL + DML (sample data, 5-10 rows per table). Use nb_execute_sql_file for all DDL+DML in one call.
2. nb_setup_collection for all 14 tables (with field upgrades + relations)
3. Build pages with nb_compose_page_file:
   a. Call nb_fields() for ALL collections FIRST. Save field names + enum values to notes.md.
   b. Read hrm-requirements.md — understand what each page is FOR.
   c. Build Reference pages first (部门, 岗位, 薪资项目) — batch 1.
   d. Build Core/Pipeline/Financial pages (员工花名册, 招聘管理, 候选人, 薪资发放) — batch 2. Each MUST have type:"js" blocks with working code.
   e. Build Activity/Alert/Target pages (考勤, 请假, 加班, 培训管理) — batch 3.
   f. Record form UIDs in notes.md!
4. JS columns (status tags, money format, date countdown) + event flows (auto-fill, auto-calculate)
5. Workflows (contract expiry reminder, leave approval, overtime approval, payroll confirmation, recruitment status update)
6. AI Employees (HR assistant, payroll advisor)
