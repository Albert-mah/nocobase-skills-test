Build a CRM (Customer Relationship Management) system in NocoBase.

## Tables (prefix: nb_crm_)

1. customers — 客户 (name, phone, email, address, industry[制造业/互联网/金融/医疗/教育/零售/其他], source[官网/展会/转介绍/电话/广告/其他], status[新客户/跟进中/已签约/流失], level[A/B/C/D], remark)
2. contacts — 联系人 (name, phone, email, position, is_primary:boolean; m2o→customers)
3. leads — 线索 (name, phone, email, company, source[官网/展会/转介绍/电话/广告/其他], status[新线索/跟进中/已转化/无效], remark)
4. lead_pool — 公海池 (reason, recycled_at:date; m2o→leads)
5. opportunities — 商机 (title, amount:decimal, stage[初步接洽/需求确认/方案报价/商务谈判/赢单/输单], probability:integer, expected_close_date:date, actual_close_date:date, source, competitor, loss_reason, remark; m2o→customers, m2o→contacts)
6. quotes — 报价 (title, amount:decimal, discount_rate:decimal, final_amount:decimal, valid_until:date, status[草稿/已发送/已确认/已过期], remark; m2o→customers, m2o→opportunities)
7. contracts — 合同 (title, contract_no, amount:decimal, start_date:date, end_date:date, status[草稿/执行中/已到期/已终止], remark; m2o→customers, m2o→opportunities)
8. contract_items — 合同明细 (product_name, quantity:integer, unit_price:decimal, subtotal:decimal; m2o→contracts, m2o→products)
9. payments — 回款 (payment_no, amount:decimal, payment_date:date, method[转账/支票/现金], status[待确认/已到账], remark; m2o→contracts, m2o→customers)
10. activities — 跟进记录 (subject, type[电话/拜访/邮件/会议], content:textarea, follow_date:date, next_follow_date:date; m2o→customers, m2o→contacts, m2o→opportunities)
11. products — 产品 (name, code, category, price:decimal, unit, status[在售/停售], description:textarea)
12. tickets — 服务工单 (ticket_no, subject, description:textarea, ticket_type[咨询/投诉/维修/退换], priority[低/中/高/紧急], status[待处理/处理中/已解决/已关闭], response_at:datetime, resolved_at:datetime, satisfaction[满意/一般/不满意], remark; m2o→customers, m2o→contacts)
13. knowledge — 知识库 (title, category, content:textarea, tags, status[草稿/已发布])
14. competitors — 竞争对手 (name, website, strengths:textarea, weaknesses:textarea, products:textarea, remark)
15. approvals — 审批 (subject, type[报价/合同/回款], status[待审批/已通过/已拒绝], related_id:integer, remark; m2o→customers)
16. targets — 销售目标 (period, target_amount:decimal, achieved_amount:decimal, status[进行中/已完成/未达标])

## Menu Structure

- CRM (group)
  - 客户管理 (group): 客户, 联系人, 公海池
  - 销售管理 (group): 线索, 商机, 报价
  - 合同管理 (group): 合同, 回款, 审批
  - 服务支持 (group): 服务工单, 知识库

Standalone pages: 跟进记录, 产品, 竞争对手, 销售目标

| 产品 | Reference | filter + table only |
| 竞争对手 | Reference | filter + table only |

## Phases

1. SQL DDL + DML (sample data, 5-10 rows per table). Use nb_execute_sql_file for all DDL+DML in one call.
2. nb_setup_collection for all 16 tables (with field upgrades + relations)
3. Build pages with nb_compose_page_file:
   a. Call nb_fields() for ALL collections FIRST. Save field names + enum values to notes.md.
   b. Read crm-requirements.md — understand what each page is FOR.
   c. Build Reference pages first (联系人, 公海池, 知识库, 产品, 竞争对手) — batch 1.
   d. Build Core/Pipeline/Financial pages (客户, 商机, 线索, 报价, 回款, 服务工单) — batch 2-3. Each MUST have type:"js" blocks with working code using ctx.api.request(). See CLAUDE.md examples.
   e. Build Alert/Activity/Target pages (合同, 审批, 跟进记录, 销售目标) — batch 4.
   f. Record form UIDs in notes.md!
4. JS columns (status tags, money format, date countdown) + event flows (auto-fill, auto-calculate)
5. Workflows (lead→opportunity conversion, contract expiry alerts, payment confirmation, ticket escalation, approval flow, target achievement check)
6. AI Employees (sales assistant, support bot, contract advisor)
